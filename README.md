# C++ 编程实践

C++ 程序设计课程实验项目合集，从基础数据结构到小型游戏开发，循序渐进地掌握 C++ 编程。

## 📁 目录结构

```
├── 01-约瑟夫环          # 数组与循环链表实现
├── 02-飞机大战          # 控制台射击游戏（状态机驱动）
├── 03-贪吃蛇(基础版)     # 经典贪吃蛇入门实现
├── 04-贪吃蛇(结构体OOP)  # 用结构体重构，面向对象思想
├── 05-贪吃蛇(链表实现)   # 链表数据结构实践
├── 06-模拟时钟          # Win32 图形绘制时钟
└── 07-迷宫游戏          # BFS 寻路 + 多关卡迷宫
```

## 🔧 技术栈

- **语言**：C++（C++11 及以上）
- **环境**：Visual Studio 2022
- **图形**：Windows Console API / EasyX

## 🚀 运行方式

1. 使用 Visual Studio 打开对应目录下的 `.sln` 解决方案文件
2. 选择 **Debug** 或 **Release** 配置
3. 编译运行（F5）

> 部分实验依赖 EasyX 图形库，请提前安装。

## 📝 知识点覆盖

| 实验 | 涉及知识点 |
|------|-----------|
| 约瑟夫环 | 数组、循环链表、指针 |
| 飞机大战 | 状态机、多对象管理、碰撞检测 |
| 贪吃蛇系列 | 链表、结构体、面向对象重构 |
| 模拟时钟 | Win32 GDI 绘图、定时器 |
| 迷宫游戏 | BFS 最短路径、关卡设计、控制台渲染 |
